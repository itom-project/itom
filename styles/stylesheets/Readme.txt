Application styles of itom
==========================

Every subfolder <name> that contains a file <name>/<name>.qss is listed as predefined
style in the itom property dialog (General > Application Style). An optional resource
file <name>/<name>.rcc with the images of the style is loaded together with it.

Alternatively, add the following section to your settings ini file (paths are relative
to the itom application folder):

[ApplicationStyle]
style=Fusion
cssFile=styles/stylesheets/modernLight/modernLight.qss
rccFile=styles/stylesheets/modernLight/modernLight.rcc
iconTheme=auto

The value of 'style' must be one of the Qt styles available on your system, e.g. Fusion,
Windows or windowsvista (and windows11 for Qt >= 6.7). The style 'plastique' that was
recommended here before does not exist any more since Qt5.

Only the .qss and .rcc files are copied to the build folder (images, .qrc and .py files
are excluded, see CMakeLists.txt). To create an .rcc file from a .qrc file, use the tool
rcc from Qt. Use the format version 2, such that Qt5 and Qt6 builds of itom can load it:

rcc --binary --format-version 2 --compress-algo zlib -o style.rcc style.qrc

The styles modernLight and modernDark (and the matching editor themes ModernLight.ini and
ModernDark.ini in styles/editorThemes) are generated by the script
modernStyleSources/generate_modern_styles.py. Do not edit the generated files directly,
but change the template or the palettes in modernStyleSources and re-run the script.
